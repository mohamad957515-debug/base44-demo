# قالب وردپرس گروه ساختمانی سهند

این پوشه، قالب وردپرس سایت است و همان طراحی سایت فعلی (hero اسکرول‌محور، پروژه‌ها، خدمات،
روند همکاری، صفحه تک‌پروژه با فرم مشاوره و صفحه تماس) را بازتولید می‌کند.

## نصب

1. کل پوشه `sahand` را zip کنید (یا `./build.sh` را اجرا کنید تا `sahand-theme.zip` ساخته شود).
2. در وردپرس: **نمایش ← پوسته‌ها ← افزودن پوسته ← بارگذاری پوسته** و فایل zip را انتخاب کنید.
3. پوسته را **فعال** کنید.

با فعال‌سازی، این موارد خودکار ساخته می‌شوند:

- برگه «خانه» به‌عنوان صفحه اصلی (تا `front-page.php` نمایش داده شود)
- برگه «تماس با ما» با قالب فرم تماس
- سه پروژه نمونه (لادن، بلوار آزادی، مهرشهر) با تصاویرشان

> اگر سرور شما به `grohesahand.com` دسترسی داشته باشد، تصاویر پروژه‌ها هنگام فعال‌سازی داخل
> کتابخانه رسانه ایمپورت می‌شوند؛ در غیر این صورت همان آدرس‌های تصویر استفاده می‌شوند.

## مدیریت محتوا

- **پروژه‌ها**: منوی «پروژه‌ها» در پیشخوان. برای هر پروژه: عنوان، تصویر شاخص، نوع پروژه،
  منطقه/شهر، گالری تصاویر، نشان «جدید» و گزینه «نمایش در پروژه‌های شاخص».
- **درخواست‌ها**: هر پیام فرم مشاوره/تماس/خبرنامه در منوی «درخواست‌ها» ذخیره می‌شود و به ایمیل
  مدیر سایت هم ارسال می‌شود.
- **برند و تماس**: نمایش ← سفارشی‌سازی ← «اطلاعات برند و تماس» (تلفن، ایمیل، نشانی، ساعت کاری).

## ساخت مجدد CSS

استایل‌ها با Tailwind ساخته شده‌اند. پس از تغییر کلاس‌ها در فایل‌های PHP:

```bash
cd wordpress-theme/sahand
npx tailwindcss -c tailwind.config.cjs -i assets/css/input.css -o assets/css/theme.css --minify
```

خروجی در `assets/css/theme.css` قرار می‌گیرد و باید همراه قالب منتشر شود.

## فونت و ویدیو

فونت ایران‌یکان و ویدیوهای hero داخل `assets/` قرار دارند، بنابراین قالب به هیچ سرویس
بیرونی وابسته نیست (به‌جز تصاویر پروژه‌ها که از سایت اصلی خوانده می‌شوند).
